# Question Design Guide

## Bloom's Weighting Defaults

| Level | Quiz | Unit Test | Exit Ticket |
|---|---|---|---|
| Remember / Understand | 30% | 25% | 40% |
| Apply / Analyze | 50% | 45% | 40% |
| Evaluate / Create-adjacent | 20% | 30% | 20% |

Question stems by level (science-flavored):
- **Remember**: define, identify, label, list, state the formula for
- **Understand**: explain why, describe what happens when, classify, summarize the process
- **Apply**: calculate, solve, predict the product, determine using the graph, balance
- **Analyze**: compare, what evidence supports, interpret the data table, which variable caused
- **Evaluate/Create-adjacent**: justify which method, critique the experimental design,
  propose a change and defend it, design a procedure to test

## Multiple Choice Construction Rules

1. The stem must be answerable before reading the choices (cover-the-options test)
2. **Distractors = real misconceptions.** Examples of good distractor sourcing:
   - Chemistry: forgot to convert grams→moles; inverted a mole ratio; used atomic
     number instead of mass; ignored a diatomic element; sig fig errors on the
     right value
   - Physics: dropped a squared term; confused mass and weight; sign error in
     direction; used speed where velocity matters; mixed units (cm vs m)
   - Geology: reversed relative-dating order; confused chemical vs mechanical
     weathering; convergent vs divergent features swapped; magma vs lava context
3. All choices grammatically parallel and similar length (length is a tell)
4. One unambiguously best answer — if two defensible, rewrite
5. Numeric choices in ascending order; each distractor reachable by a specific error
6. Banned: All/None of the above, "A and C", double negatives, trivia about
   irrelevant details

## Calculation Question Rules

1. **Solve every problem yourself during generation.** Verify the answer is clean-ish
   (2–4 sig figs, physically sensible). If it's ugly, change the givens.
2. Physically realistic values (no 900 kg baseballs, no 15 M HCl in a classroom context)
3. State required constants or point to the reference box
4. Sig figs in givens should support the expected sig figs in the answer
5. Version B: change values enough that copying A's answer is useless, but keep the
   same solution path and comparable arithmetic load

## Short Answer / Extended Response Rules

1. Specify the expected scope: "in 2–3 sentences," "give two reasons," "using the terms
   ___ and ___"
2. Verbs match the Bloom's level — don't write "explain" if you'll grade for a definition
3. Key must include acceptance criteria, not just one model answer

## Anti-AI Quality Bar

- Vary stem constructions across the document
- Teacher voice in directions; contractions are fine
- No em-dash chains, no "delve," no bullet-point questions
- Real-world contexts must be plausible for Ohio HS students (local rivers, Cedar
  Point physics, Lake Erie, Ohio geology like Serpent Mound or glacial features) —
  used naturally, at most a few per assessment
- A question should never telegraph its own answer through grammar or specificity

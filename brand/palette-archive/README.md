# Palette archive

Superseded palettes, preserved. Part 47 forbids deleting legacy material; keeping these here means
nothing is lost and nothing is live.

This directory is what `SHULL_Color_Palette_Library.md` was specified to be and never became. That
absence is why a rejected back-burner option was later revived as a locked decision without anyone
noticing it had been passed over.

**which existing materials were built on it** — so the Janitor does not later flag them as defects.

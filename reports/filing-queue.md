# Filing queue

Rules: `standards/DRIVE_ARCHITECTURE.md` §8 (SHULL-CHG-0027).

**How to use it.** When a document passes the QA gate, the Overseer adds a row, unticked. To approve
it, tick the box, or say "file it" in chat. Agents never tick a box. The Librarian files the student
file, the key and the PDF together. The Overseer then fills in Status, Drive path and File ID.

**Status** is `Ready` (waiting for you), `Filed`, or `Not filed` with the reason.

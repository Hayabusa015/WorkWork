# SHULL-CHG-0106 — Textbook page designer and independent science review

| Field | Value |
|---|---|
| Change ID | SHULL-CHG-0106 |
| Date | 2026-11-24 |
| Source | User request for a reusable textbook designer and an independent accuracy audit. |
| Current Rule | The Overseer routes “Build the deliverable to the design system” to the Designer and “Independent QA” to the Auditor in its Delegation table. |
| Proposed Rule | For unit textbooks and textbook chapter creations or revisions, the Overseer routes the build to a specialist textbook page designer and sends the resulting artifact to the existing Auditor for independent scientific and print review. The specialist uses research on printed learning materials and draws on the approved decisions for the selected course. |
| Supersedes | The generic Designer assignment in the Overseer delegation table for textbook builds only. |
| Reason | Explanatory chapters require a sequence of scientific representations, worked reasoning and readable figures across pages. Their facts, figures and answer keys need an independent check against sources and fresh calculations. |
| Affected Agents | Overseer, textbook page designer, Designer, Auditor and Researcher. |
| Affected Skills | Textbook build guidance, verify-content and audit-deliverable. |
| Affected Courses | Chemistry, Physics and Geology. |
| Risk | Low. Scope is limited to textbook builds. The existing filing, approval and independent QA responsibilities continue. |
| Recommendation | Register the specialist with assigned-artifact authority, route new and revised unit textbooks through it, and require the existing Auditor to review the rendered edition before release. |
| Decision | Awaiting the main session's record. |
| Status | PENDING |
| Implemented By | Pending implementation. |
| Verified | Pending verification of routing, authority checks and review instructions. |

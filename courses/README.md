# courses — Layer 2, what is taught

One `DECISIONS.md` per course. **This is the only authoritative home for a course fact.** If a skill
states a course fact and the decisions file disagrees, the decisions file wins and the skill is
reported stale.

Holds: curriculum map · pacing and calendar · policies · assessment shape · lab and activity
philosophy · reference packet · course brand exceptions · open questions · decision log.

Does **not** hold build mechanics. Those are standards and skills.

Every entry in the decision log carries a `Supersedes:` line. That line is what makes drift visible
instead of silent.

# anti-ai-slop

Standard: `standards/ANTI_AI_SLOP_STANDARD.md`. Voice: `standards/VOICE.md`. This is the runnable
pass.

## The test

> **Would this actually look like something the teacher would hand to students?**

If not, revise it. That question outranks every item below.

## The pass, in order

**1. Specificity.** Does this reflect *this* course, *this* unit, *these* students? Name the unit,
the prior knowledge, the class time, the expected product. If a missing detail would change the
assignment, **ask**. If not, assume and say so in the teacher notes — never on the student page.

**2. Padding.** Delete anything that does not earn its place. Every question, box, heading, graphic,
and instruction. A reflection section added by default rather than by instructional need is padding.

**3. Voice.** Read the directions aloud in your head. Any sentence that sounds like a brochure gets
rewritten. Then run the audit list in the standard — **as an audit, not a word ban.**

**4. Task design.** Vary the thinking, not just the numbers. Ten questions with identical structure
and different numbers is a defect unless fluency is genuinely the goal — and if it is, say so.

**5. Visual tells.** Work the list in the standard. The ones that show up most: a coloured banner per
subsection · excessive cards · repeated Objective/Materials/Instructions/Reflection regardless of
task · answer blanks too small for the expected response.

**6. Accuracy.** Nothing fabricated — sources, accepted values, chemical properties, safety
guidance, standards codes. **Never invent a safety claim.** Never attribute an invented statement to
Mr. Shull.

**7. The final audit.** Section 10 of the standard: voice, instructional design, accuracy,
appearance, authenticity. If any answer reveals a problem, revise before delivery.

## When revising existing work

> **Preserve its useful personality and routines.** Improve weak areas without replacing everything
> with a generic template.

A file that has been used in a classroom carries decisions in it. Find out what they were before
overwriting them.

## Interactive output

If the deliverable is an HTML tool or dashboard rather than a document, use section 8 of the
standard instead of the visual-tells list.
